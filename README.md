# Shelfetto

Shelfetto – Simple Inventory. Depodaki malzemeleri (gıda, araç bakım, tamir/yedek…) takip etmek için kişisel, çevrimdışı çalışan Android uygulaması.

- Veriler sadece telefonda saklanır, internet gerekmez.
- Son kullanma ve garanti tarihleri yaklaşınca bildirim gönderir.

## APK nasıl alınır
`main` dalına her yükleme yapıldığında GitHub Actions APK'yı otomatik derler ve **Releases** bölümüne koyar.
En yeni sürüm: **Releases → Latest → kiler-N.apk**

`keystore/debug.keystore`, güncellemelerin eski sürümün üzerine kurulabilmesi için sabit tutulan imza anahtarıdır.
